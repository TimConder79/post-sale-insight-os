# MVP Roadmap

Issue #13 adds **Phase 5A — AI-Assisted Insight Workflow** after Themes; the approved mockup/Today redesign is next, with later workflows still deferred.

Issue milestones govern earlier implementation scope: Issue #11 names **Phase 4 — Themes** (manual subjects and explicit approved-Insight membership). The original numbered plan below predates that milestone; Relationships/Next Actions, Weekly Review and Content Ideas remain deferred, not part of Issue #11.

## Phase 0 — Foundation
- Establish app scaffold and local development.
- Choose/initialize database.
- Implement schema and migrations.
- Establish environment/secrets pattern.
- Add basic tests/lint/typecheck.

## Phase 1 — Post Workspace
- Create Source Conversation.
- Paste/preserve post and comments.
- Optional URL/person metadata.
- AI analysis with seed/theme suggestions.
- Editable comment draft.
- Editable insight proposal.
- Save source and derived data independently.

**Exit:** one real LinkedIn conversation can become a saved source + approved insight without data loss.

## Phase 2 — Insight Library
- List/search/filter insights.
- Insight detail and lineage.
- Edit user-approved derived fields.

## Phase 3 — Connections + Synthesis
- Manual connection creation.
- Map + list views.
- AI connection suggestions with rationale.
- Multi-select synthesis into a new Insight with lineage.

**Exit:** the core Miro behavior is replaced without building a whiteboard.

## Phase 4 — Relationships + Next Actions
- People and timeline.
- Manual events.
- Next-action suggestion and due date.
- Today action queue.

## Phase 5 — Weekly Review
- Weekly evidence collection.
- Learning/pattern/tension synthesis.
- Content recommendations.
- Relationship follow-up recommendations.
- Next-week focus.

## Phase 6 — Real-use gate
Run five real LinkedIn conversations through the complete loop. Fix friction before adding scope.

## Later / only after gate
Content Ideas polish, saved-search management, optional technical-health ingestion, meeting/outreach source types, richer semantic search.
